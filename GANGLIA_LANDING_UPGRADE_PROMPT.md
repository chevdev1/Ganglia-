## 1. Что такое Ganglia сейчас (актуально, не выдумка)

Это **рабочее приложение**, не симуляция:

- Один общий цифровой персонаж. У него **128 узлов**, у каждого узла один владелец.
- **Подключение кошелька настоящее**: injected-кошелёк + подпись сообщения (`js/wallet.js`),
  без случайных ключей. WalletConnect QR опционален через `WALLETCONNECT_PROJECT_ID`.
- **Claim настоящий и бесплатный**: один свободный узел на кошелёк, узел не передаётся, повторное
  подключение сохраняет владение. **Токена $GNGL и сжигания нет** — это было в старой версии ТЗ,
  в текущем продукте claim ничего не сжигает.
- Владелец узла отправляет **сценарии** (память, вопрос, ситуация), максимум 280 символов,
  проходят PII-фильтр на бэкенде.
- Ответы пишет **язык-модель через Groq** (`GROQ_API_KEY`, бесплатный ключ), либо локальный
  software-writer как честный fallback без ключа. Это видно в UI как `writer: model` /
  `writer: software`.
- Память общая и настоящая (SQLite, `backend/services/memory.py`), не выдумка на фронте.
- Автономные мысли — примерно раз в минуту, бэкендом.
- Есть **кабинет** (`me.html`) и **steward-консоль** (`admin.html`) для модерации: скрыть мысль,
  посмотреть узлы, статистику. Обе страницы уже используют общую пиксельную систему.
- Визуальная метафора: пиксельный 3D-мозг, 128 узлов на коре, **зонд**, который входит в узел и
  запускает волну сигнала.

### Правила честности (обязательны, это часть бренда)
- Всегда показывать источник сигнала (`signal source: software|model`) и то, кто пишет
  (`writer: software|model`).
- Никогда не называть узел долей, инвестицией или частью живой ткани.
- Не обещать доходность, «AI сознание», «живой мозг».
- Сценарии публичны, это нужно явно показывать перед отправкой.
- **Нет токена, нет сжигания.** Не выдумывай $GNGL обратно в копирайт — его больше нет в продукте.
- Честно показывать реальные лимиты: один узел на кошелёк, узел не передаётся, модерация есть
  (steward может скрыть мысль).

## 3. Диагноз: почему сейчас выглядит так

Актуально независимо от бэкенда — это про фронтенд-слой:

1. **Нет режиссуры.** Страница просто появляется. Нет входа в hero, нет истории при скролле.
   *(Частично закрыто в Фазе 1: hero теперь входит через scramble/lineReveal/ditherReveal, см. §10.)*
2. **Одинаковый ритм.** Все секции — одинаковые блоки с `border: 1px` и одинаковыми отступами.
3. **Статичная типографика вне hero.**
4. **Карта 128 узлов — плоская сетка квадратов**, визуально не связана с 3D-мозгом.
5. **Claim — это таймер и текст на кнопке.** Нет ощущения транзакции (хотя транзакция настоящая —
   подпись кошелька), нет момента награды.
6. **Лента мыслей — обычные карточки.** Нет ощущения «разум думает прямо сейчас» вне анимации печати.
7. **Мало микро-взаимодействий.** Кнопки, копирование, фокус, hover сделаны по минимуму.
8. **Не хватает доверия и глубины.** Не хватает FAQ, объяснения памяти, модерации, честного
   разбора «что реально, что нет» на самом лендинге (частично есть в `docs.html`).
9. **Мобильная версия второстепенная.** Мозг тяжёлый, сетка скроллится горизонтально.
10. **Нет «фишек»**, которые запоминаются и которыми делятся.
11. Нет OG-картинки, анимированного favicon, кастомного 404.

## 4. Дизайн-принципы (не нарушать)

### 4.1 Айдентика
- Палитра остаётся: `--bg #000`, `--fg #F2F2F2`, `--acc #4D7CFF`, `--cell #161616`, `--dim #7A7A7A`.
  Светлая тема тоже остаётся.
- **Синий — дефицитный ресурс.** Он означает «сигнал / своё / активное». Никаких синих тонов
  секций и декоративных линий-градиентов.
- Шрифты: **Silkscreen** для дисплейных элементов, **Geist Mono** для текста. Можно добавить *одну*
  пропорциональную гарнитуру для длинного текста, но только если обоснуешь.
- Пиксельная сетка — основа. Отступы кратны 4px, иконки чистятся на пиксельной сетке
  (SVG `shape-rendering: crispEdges`).

### 4.2 Главный motion-принцип бренда
> **«Шаги для состояния, плавность для пространства».**

- Смена **состояния** (статус узла, мигание, появление символов, счётчики, индикаторы) идёт
  **ступенчато**: `steps()`, дизеринг, пиксельные кадры. Это цифровой разум.
- Движение в **пространстве** (скролл, параллакс, вращение мозга, перемещение панелей) идёт
  **плавно** на expo-кривых. Это дорого и физично.
- Сочетание этих двух режимов и есть почерк Ganglia. Не смешивай их хаотично.
- Реализация примитивов уже есть в `js/motion.js` (Фаза 1): `ditherReveal`, `scramble`,
  `lineReveal`, `countUp`, `drawPath`, `magnetic`, `onEnterView`. Используй их, не изобретай новые
  CSS-анимации там, где подходит существующий примитив.

### 4.3 Анти-паттерны (запрещено: это выдаёт «AI-сборку»)
- Фиолетово-розовые градиенты, glassmorphism, blur-карточки, неоновые glow-тени.
- Одинаковый `fade-up` на каждом элементе с одинаковой задержкой.
- Bounce/elastic easing на UI.
- Эмодзи в качестве иконок.
- Фразы «Unlock the future», «Revolutionary», «Join the revolution», «Web3 meets AI».
- Три одинаковые карточки в ряд как единственный приём вёрстки.
- Бесконечные marquee без смысла, фейковые логотипы «as seen on».
- Мозг в стиле «розовая 3D-модель из стока».
- Анимации, которые блокируют чтение или скролл дольше 1 секунды.
- **Выдуманные цифры.** Если показываешь статистику (claimed, scenarios, uptime) — бери из
  `/api/state`, не хардкодь демо-значения.

## 5. Motion-система (Фаза 1 — сделано, см. §10)

Токены и примитивы уже в `css/styles.css` (`:root`) и `js/motion.js`. Кратко:

```css
--ease-out: cubic-bezier(.16,1,.3,1);      /* пространство */
--ease-in-out: cubic-bezier(.65,0,.35,1);
--ease-snap: cubic-bezier(.2,0,0,1);       /* hover, нажатия */
--d-1: 120ms;  --d-2: 240ms;  --d-3: 480ms;  --d-4: 900ms;
--steps-ui: steps(4, end);  --steps-reveal: steps(12, end);
```

Примитивы в `js/motion.js` (глобальные функции, без модулей, как и весь остальной код):
`ditherReveal(el)`, `scramble(el)`, `lineReveal(el)`, `countUp(el, to)`, `drawPath(pathEl)`,
`magnetic(el)`, `onEnterView(el, cb)`. Все уважают `prefers-reduced-motion` (глобальный `reduce`
из `core.js`) и не повторяются при обратном скролле.

### Правила хореографии
- **Одна сигнатурная анимация на вьюпорт.** Остальное вторично и тише.
- Порядок входа внутри секции: заголовок (scramble) → лид (lineReveal) → визуал (ditherReveal) →
  вторичные элементы (простой stagger через `onEnterView`).
- Появление триггерится при 20–25% видимости и **не повторяется** при скролле вверх.
- Scrub-анимации (скролл = повествование) — только там, где это оправдано: story-секция, зонд.
- `prefers-reduced-motion: reduce` — мгновенные состояния, без scramble/scrub, мозг не
  авто-вращается.
- Анимируем только `transform`, `opacity`, `clip-path` и canvas. Никаких анимаций `width`, `top`,
  `box-shadow` на скролле.

## 6. Секции лендинга

### 6.1 Header
- Высота 64px, фон `--bg`, снизу — **индикатор прогресса чтения страницы** (не прогресс claim'ов
  узлов — это разные вещи, не путать в копирайте).
- При скролле вниз прячется (`translateY`, `--ease-out`), при скролле вверх — появляется.
- Активная секция подсвечивается в навигации.
- Кнопка кошелька уже реальная (`js/wallet.js`, `#connect`/`#leave`/`#profile`) — не переделывай
  логику, только визуальную полировку (hover, транзишены состояний).

### 6.2 Hero: «One mind. 128 nodes.»
- Уже: kicker, h1 через scramble, lede через lineReveal, CTA stagger, мозг через ditherReveal
  (Фаза 1).
- Добавить: **live-строка под CTA** с реальными цифрами через `/api/state`:
  `46/128 claimed · 312 scenarios · last thought 2m ago`. Числа — через `countUp` **только при
  первой загрузке**; последующие обновления (каждые 3с поллинг) — тихая замена текста без
  дёргающегося countUp на каждый tick, иначе раздражает.
- Мозг реагирует на курсор: лёгкий параллакс-наклон (≤4°) даже без drag.
- Подсказка `drag to rotate` появляется через 3с бездействия, исчезает после первого
  взаимодействия.

### 6.3 How it works: Claim / Send / Watch
- Уже есть базовый reveal (Фаза 1). Текст шагов должен отражать **реальный** продукт: claim
  бесплатный и привязан к кошельку, не к токену.
- Можно усилить горизонтальной схемой-процессом (`node → wallet signature → shared memory →
  thought`) со связями через `drawPath`, но это не обязательно для премиализации — приоритет ниже,
  чем доверие и честность копирайта.

### 6.4 Карта 128 узлов
- Hover по ячейке: подъём на 2px, соседние узлы (граф `NB`, если появится) подсвечиваются, в
  мозге выделяется этот узел.
- Claim flow уже реальный (подпись кошелька → сервер). Полировка: пиксельный прогресс каждого шага
  (`connect → sign → claim` вместо старого `approve → burn → register` из версии с токеном),
  честный текст ошибок (узел уже занят, отказ в кошельке).
- Момент награды при успешном claim: ячейка вспыхивает синим, в мозге зонд входит в узел, волна
  проходит по графу. ≤1.2с, без конфетти.
- После claim — карточка «Share your node» (PNG 1200×630: мозг под своим ракурсом, номер узла,
  identicon, wordmark). Кнопки Download и Post on X.

### 6.5 Thoughts: лента мыслей
- Уже есть анимация печати посимвольно для новых мыслей (`js/app.js:renderThought`). Полировка:
  копировать ссылку/шарить на hover, дельта состояний (`curiosity +1`) как мелкие ступенчатые чипы.
- Фильтры: all / scenarios / autonomous / my node — без прыжков высоты (FLIP).

### 6.6 Доверие и прозрачность (заменяет старую секцию про $GNGL)
Токена нет, поэтому вместо «токеномики» — секция честности, это сильнее для web3-аудитории,

- Как работает модерация (steward может скрыть мысль, PII-фильтр на сценариях).

- Ссылка на `CONSTITUTION.md` / `docs.html` как на «конституцию» персонажа.
- Явно: нет токена, нет инвестиции, узел не передаётся.

4. Консольное пасхальное яйцо: ASCII-мозг и `128 nodes. one mind. read the docs: /docs.html`.
5. Секрет: набрать `128` — все узлы мозга дают волну одновременно.
6. Сочетания клавиш: `?` — шпаргалка, `/` — фокус на composer, `t` — смена темы.
7. Смена темы через дизеринг по Байеру (уже есть паттерн в `motion.js`, можно переиспользовать
   `ditherReveal`-подобный приём для перехода).
8. Копирование id узла или адреса кошелька с пиксельным тостом.
9. Idle-режим: через 60с бездействия мозг «сноводит», волны идут сами по случайным маршрутам.
