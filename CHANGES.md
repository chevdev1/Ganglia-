# Что сделано в Ganglia (понятным языком)

Краткий отчёт по продукту: что починили, что добавили, как пользоваться.

Тесты перед пушем: **18 passed**.

---

## Главная идея сейчас

Ganglia — один общий персонаж на 128 местах (nodes). Люди заходят через браузерный ключ / кошелёк, занимают место, пишут сценарии. Ответы пишет модель (Groq), а не шаблонный «software»-голос — если ключ есть и сервер не упирается в лимит.

Между ответами персонаж **помнит** и **меняет настроение**: это не чатбот с нуля каждый раз.

## Память и «живой» персонаж (главное техническое)

Раньше модель часто получала один огромный prompt и в том же ответе пыталась и говорить, и менять state — либо падала в software-шаблоны.

Сейчас петля как в продуктовом ресерче:

1. **Слоистый system prompt** из lore (личность, правила, safety) — без сырой памяти внутри.
2. **Рантайм-контекст отдельно**: summary + недавние мысли + память ноды + текущий state + ввод пользователя.
3. **Ответ** — обычный текст персонажа.
4. **Второй тихий вызов** — JSON: что запомнить, как сдвинуть curiosity/intensity/warmth/focus/restlessness, какой unresolved thought оставить.

Если второй вызов падает (лимит Groq и т.п.), **ответ персонажа больше не выбрасывается**.

Также:

- сжатый prompt, чтобы реже ловить TPM 429 у free Groq;
- retry при rate limit;
- в тестах модель отключена (только software), чтобы suite не вис на API.

Файлы lore: `LORE.md`, `backend/lore/SYSTEM.md`.

## Админка Steward

Страница: `/admin.html` (в главном меню её нет специально).

Нужен `ADMIN_TOKEN` в `.env`.

Там теперь нормальная ops-консоль:

- **Overview** — cycle, writer, места, юзеры, мысли;
- **Archive** — поиск, фильтр public/hidden, Hide / Restore;
- **Memory** — summary, unresolved, метры, последние сценарии;
- **Seats** — карта 128 мест.

API: `/api/admin/overview`, `/api/admin/thoughts` (с фильтрами).

## Как запустить локально

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
# GROQ_API_KEY=...  и  ADMIN_TOKEN=...
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8080
```

Открывать только через сервер, не как файл `index.html`.

```powershell
pytest
```

## Важно не перепутать

- **Кабинет** = личное место (`/me.html`), не пункт в главном меню.
- **Steward** = админка (`/admin.html` + токен).
- Если ответы снова «шаблонные» (`i kept … next to the older things`) — почти всегда старый процесс uvicorn или лимит Groq; нужен один перезапущенный сервер и Ctrl+F5.
- `.env` в git **не** коммитится (секреты).
